# product-management-api-34291-34318

This workspace contains the Product API backend implemented with Express, providing CRUD endpoints for managing products.

- Base URL: http://localhost:3001
- API Docs (Swagger UI): http://localhost:3001/docs

Quick start:
- Change directory: `cd product_api_backend`
- Install: `npm install`
- Start: `npm start` (server listens on PORT env var or 3001 by default)

For detailed usage of product endpoints, including curl examples, see product_api_backend/README.md.
